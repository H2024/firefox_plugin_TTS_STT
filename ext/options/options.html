Moonshine Voice

Push-to-talk dictation that runs entirely on your machine. The model is downloaded once from Hugging Face and then cached; your audio is never uploaded anywhere.

1. Allow Moonshine on web pages

Firefox asks for this separately. Without it, the hotkey can't reach the page you're typing into.

Model

WebGPU is much faster but is only available in recent Firefox builds on supported hardware. Automatic falls back to the CPU on its own.

The runtime ships inside the add-on. If Firefox refuses to read it — some installations do — the identical build can be fetched from jsDelivr instead. Those are bytes handed to the loader compiled into the add-on, so no remote code is executed. Diagnostics say which route was used.

Dictation

Click and press the combination you want. Escape cancels a recording in progress. There is also a built-in toolbar shortcut (Ctrl+Shift+Y) that works as a start/stop toggle and can be changed in Add-ons → gear icon → Manage Extension Shortcuts.

Moonshine is a short-form model. Long recordings still work but accuracy and latency are best under about 30 seconds per utterance.

Read aloud

Select text on a page and press it; press again (or Escape) to stop. Right-clicking a selection offers Read aloud with Moonshine Voice as well, and you can assign a browser-level shortcut to Read the selected text aloud under Add-ons → gear icon → Manage Extension Shortcuts.

Microphone & panel

The panel holds the microphone and the loaded model, so it needs to be open while you dictate. Open it with the toolbar button or Ctrl+Shift+U.
