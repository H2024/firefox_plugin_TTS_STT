# Firefox plugin Text to speech (TTS) and speech to Text (STT)
Firefox plugin for human realistic voice Text-to-Speech and Speech-to-Text 
This plugin code is written by Claude code. 
And for Read aloud voice engine using Kokoro 82M locally neural voices. 
And for Push-to-talk Moonshine voice 1.6.0 (Moonshine Base - English (150MB best accuracy is used)) 

How to use it git clone this repository. Start Firefox browser on windows
1. In the URL address bar, type **about:debugging** and press Enter. 
2. Locate the Temporary Extensions section on the page.
3. Click the "Load Temporary Add-on..." button.
4. In the file explorer popup, navigate to your extension's development folder and select either your manifest.json file.
5. Once loaded, your extension will appear in the list under Temporary Extensions.
6. Click the "Inspect" button next to your extension's name.
7. Go to, any other tab of the same Firefox browser select text and right click and you see the "Read aloud with Moonshine Voice" 

Only tested on windows.
